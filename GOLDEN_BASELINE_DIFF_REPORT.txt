RMU name fallback safety rule
-----------------------------
- Existing selected-direction Text matching always runs first and is unchanged.
- Metadata fallback is NOT metadata-only: a unique BusDis.key_name such as 38995_BUS
  must be confirmed by nearby Text whose complete value is exactly 38995 in one of
  the user-selected directions.
- User exclusions use complete-string, case-insensitive matching after trimming;
  excluding SFI does not exclude SFI-1201.
- Exclusions apply to both Text candidates and metadata fallback candidates.
