# G File Studio v2.17.30 验证报告

## 本次范围

本版本只调整 **ID 检查与修复** 与 **异常短线图元检测** 两个页面的操作布局、日志/报告呈现和结果复制能力；不修改既有 ID 模板推断确认流程、ID 修复算法、异常短线判定算法及其他模块业务逻辑。

## ID 检查与修复

- 移除 ID 规则模板下方重复展示的大段扫描详情，扫描详情统一写入“执行与日志”。
- “扫描当前 G”和“只检查 ID”合并为一个明确动作：`扫描当前 G（只检查 ID）`。
- `检查并强制修复 ID` 作为独立动作按钮，与扫描动作并列放在“执行与日志”。
- 扫描当前 G 时继续保留新元素类型候选规则的逐条人工确认流程；不会自动加入未确认规则。
- 扫描当前 G 每次生成独立 CSV + HTML 报告，文件名带时间戳且避免覆盖历史报告。
- “打开本次 HTML 报告”保持为独立按钮。
- 扫描/修复输出均写入可复制的日志区域。

## 异常短线图元检测

- 结果表保留，用于多选和“删除选中异常图元”。
- 结果表新增 Ctrl+C 复制：复制当前选中数据并带表头，可直接粘贴到 Excel 或文本编辑器。
- “删除选中异常图元 / 删除全部异常图元”移动到异常结果区，和结果表形成一个操作组。
- “执行与日志”只保留扫描、打开本次 HTML、打开输出目录、清空日志等任务级操作，减少按钮混杂。
- CSV/HTML 时间戳报告与 keyid 删除确认逻辑保持不变。
