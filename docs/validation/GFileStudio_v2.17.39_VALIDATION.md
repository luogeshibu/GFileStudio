# G File Studio v2.17.39 Validation

本版本仅调整“异常小尺寸图元检测”的处理状态与处理报告颜色，其他模块及业务算法不修改。

## 本次变更

- 每次“删除选中异常图元”都重新读取原始 G，仅按本次勾选项生成输出。
- 不读取上一次输出 G，不累计上一次已处理项目；同名输出 G 和处理 CSV/HTML 每次覆盖。
- 执行完成后“异常图元结果”仍保留本次扫描得到的完整原始检测快照；只清空勾选状态。
- 只有重新点击“扫描异常图元”或更换输入后重新扫描，结果表才刷新。
- 扫描 HTML 仍以红色系表示异常项；处理 HTML 中成功“已删除”的行使用绿色系，并突出 `ProcessResult=已删除`。

## 验证

- `python -m py_compile`：通过。
- `pytest -q`：217 passed。
- 手工引擎验证：同一原始 G 含 2 个异常图元，第一次删除 A 后输出仅删除 A；第二次只选择 B 再执行，输出重新基于原始 G，因此 A 恢复、B 删除，确认不存在累计处理状态。
- 手工 HTML 验证：处理报告成功行包含绿色 `processed` 样式和“已删除”结果。
