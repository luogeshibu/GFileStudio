# G File Studio v2.17.32 验证报告

本版本仅调整“ID 检查与修复”和“异常小尺寸图元检测”两个页面的交互布局与文案，不修改既有 ID 扫描/规则确认/强制修复算法，也不修改异常图元判定与处理算法。

## ID 检查与修复
- 扫描按钮文案改为“扫描当前G文件（只检查ID）”。
- 报告按钮简化为“打开报告”。
- 删除“加入扫描发现的规则”按钮。
- 扫描发现可推断的新元素类型后，仍会主动询问是否逐条确认加入模板；用户可逐条确认或取消，原确认流程保持不变。

## 异常小尺寸图元检测
- 模块名称由“异常短线图元检测”恢复为“异常小尺寸图元检测”。
- “扫描异常图元”按钮移动到“异常图元结果”区域。
- 执行与日志区域不再重复放置扫描按钮。
- 结果表选择、复制、全选处理、执行选中处理、CSV/HTML 报告与 keyid 二次确认逻辑保持不变。
