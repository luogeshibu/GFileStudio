# G File Studio v2.17.15 验证报告

## 本次范围

本版本基于 v2.17.14，仅调整 ID 检查与修复模块的全局定位、模板启用状态和规则生命周期，不修改环网柜识别、馈线单母线合并等既有业务算法。

## 关键行为

1. “ID 检查与修复”位于“基础处理”之前，作为全局 ID 规则中心。
2. ID 规则模板增加“启用”复选框列，启用/停用立即写入持久化配置。
3. 扫描当前 G 时统计所有带 ID 的 XML 类型，并与模板逐类比较；未覆盖类型进入候选/待人工新增流程。
4. 对可推断的新类型，自动预填 XML 类型、固定前缀、ID 总位数，再由用户逐条确认后才加入模板。
5. 删除规则会立即写入 deleted_tags；重新加载规则不会自动恢复已删除的内置规则。
6. 对已经有已确认规则的类型，格式异常和重复 ID 继续严格按照“前缀 + 总位数 + 同类型最大合法完整 ID + 1”修复。
7. 基础处理、馈线合并、图形边距调整、图框添加输出仍统一调用全局模板规范化逻辑。
