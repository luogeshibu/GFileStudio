# G File Studio v2.17.16 验证报告

## 本版本变更

1. ID 规则模板首列为“选择”复选框，可一次勾选一条或多条规则后批量删除；不再把首列作为规则启用/停用状态。
2. ID 规则本身始终启用；“全局 ID 模板强制约束”为独立总开关，默认开启，用户可关闭。
3. 关闭全局强制约束后，已有且格式不符合模板的 ID 保留不变；新生成 ID 仍优先按已确认模板生成。
4. 馈线合并“输出文件名”移动到布局参数之后、“执行与日志”之前。
5. 历史版本验证报告移动到 `docs/validation/`。
